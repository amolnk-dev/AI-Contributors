# Core Beliefs — Agent-First Competition

1. **Speed over perfection** — Ship a baseline first, iterate. A working 60% solution beats an unfinished 95% one.

2. **Each task independent** — Parallelize across agents. Never block one task on another.

3. **Validate before final submit** — You get ONE shot at final evaluation. Test thoroughly.

4. **No cloud APIs at inference time** — All models must run on our own infrastructure.

5. **Repository is the record** — Log all task analysis, strategies, and findings in docs/. If it's not in the repo, it didn't happen.

6. **Time-box exploration** — 2 hours max for analysis, then implement. Don't rabbit-hole.

7. **Breadth wins** — 2025 winner pattern: reliable solutions across ALL tasks beats excellence in one.

8. **Automate overnight** — Use autoresearch pattern for continuous improvement while sleeping.

9. **GPU time is precious** — Start training early, iterate fast. Don't waste GPU hours on dead-end approaches.

10. **Simple beats complex** — AutoGluon > custom architecture, pretrained > from scratch, ensemble > single model.
